# 🎯 Customer Retention & Intervention Engine

An interactive, end-to-end Machine Learning web application that predicts customer churn risk in real-time and enables business teams to run "What-If" simulations using actionable service levers.

## 🚀 Key Engineering & Architecture Features

* **Advanced Predictive Core:** Built and optimized a robust **XGBoost Classifier** trained on processed customer account data to map non-linear risk patterns.
* **Explainable AI (XAI):** Integrated **SHAP (SHapley Additive exPlanations)** values into the training pipeline to extract exact feature weights, transforming a black-box model into transparent, auditable business insights.
* **Dynamic Simulation Interface:** Developed a fully responsive frontend application using **Streamlit** that recalculates class probabilities instantly when account parameters change.
* **Secure Production Tunneling:** Managed application exposure architecture utilizing secure **Ngrok** network tunneling protocols for zero-cache testing.
